# 로그 이미지 생성기

정적 HTML/CSS/JavaScript만으로 동작하는 로그 이미지 생성기입니다.

## 사용
`index.html`을 브라우저에서 열거나 GitHub Pages에 올리면 됩니다.

## GitHub Pages
1. 새 GitHub 저장소를 만듭니다.
2. `index.html`, `style.css`, `app.js`를 저장소 최상단에 업로드합니다.
3. Settings → Pages → Deploy from a branch 선택.
4. Branch를 `main`, 폴더를 `/ (root)`로 선택 후 Save.
5. 잠시 뒤 표시되는 Pages 주소로 접속합니다.

## 들어간 기능
- 본문 편집/서식 태그
- 좌우 말풍선, 심플/카카오톡/iMessage 스타일
- 따옴표·괄호 자동 감지
- 제목/소제목/하단 문구
- 글꼴 파일 업로드
- 글자 크기/자간/행간/문단 간격/장평
- 단색/그라데이션/이미지/투명 배경
- 1단/2단, 고정 비율
- 인라인 사진
- 프리셋(localStorage)
- 설정 코드 복사/적용
- PNG/JPG/WEBP 저장
- `===` 기준 분할 저장
- 자동 임시저장

## 표기법
- `> 대사` : 왼쪽 말풍선
- `< 대사` : 오른쪽 말풍선
- `|a 문장`, `|b 문장` : 강조 막대
- `---` : 구분선
- `===` : 페이지 나눔
- `<b>`, `<i>`, `<c>`, `<ha>`, `<hb>`, `<q>` : 글자 꾸밈

## 참고
원본 사이트의 코드를 복사한 것이 아니라, 공개적으로 보이는 기능을 참고해 새로 구현한 별도 코드입니다.

- UI를 연분홍 패널/버튼/슬라이더 중심의 레퍼런스 스타일로 조정했습니다.
